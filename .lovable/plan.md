## 1. Freeze semantics and diagnostics
- Exactly two operands, evaluated once in source order. Require array source and finite nonnegative safe-integer numeric count; reject coercion, negative/fractional/null/undefined/boolean/string/non-finite/unsafe values.
- Validate both arguments before zero/empty returns. `-0` equals zero; zero gives fresh `[]`; positive count gives a new shallow suffix capped at length. Never mutate or blindly call slice(-count).
- Permit only trusted lastN AST dispatch, not context functions, computed names, methods, callbacks or host access. Preserve bare input identifier lastN, nested helper composition and ordinary post-result members/indexing; do not invent Python projection on function results.
- Scope helper support to typed callers and keep compiler/cache feature options distinct. Generic grammar never switches through exception fallback.
- Preserve pure native types, mixed strings, whitespace, original-input semantics, destination checks and existing literal [-0:] behavior. Array destination accepts native suffix, not interpolation text.
- Separate missing identity, ambiguous alias, unavailable output, invalid source/count, resource and serialization diagnostics with node/row/field/argument/path positions. Strict reference checks apply only in evaluated helper subtrees; preserve unrelated undefined reads and short-circuiting.
